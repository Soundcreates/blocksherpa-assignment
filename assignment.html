Task Overview

Write a simple Property Registry smart contract, deploy it to Polygon Amoy testnet, and integrate it with the real estate test platform. You can find the real estate Github codebase attached above.

Part 1: Smart Contract (2-3 hours)

Write a Solidity contract called PropertyRegistry.sol with the following features:

Requirements:

  • Register a property with address, owner, and price
  • Transfer ownership to another address
  • Anyone can view property details
  • Emit events for registration and transfer

Contract Structure:

// SPDX-License-Identifier: MIT pragma solidity ^0.8.19; contract PropertyRegistry { // Your code here }

Functions to implement:

  • registerProperty(string memory _address, uint256 _price) - Register a new property
  • transferOwnership(uint256 _propertyId, address _newOwner) - Transfer ownership
  • getProperty(uint256 _propertyId) - View property details

Hint: Use a struct to store property data and a mapping to track properties.

Write one Foundry or Hardhat test to verify:

  • A property can be registered
  • Ownership can be transferred
  • Only the owner can transfer

Part 2: Frontend Integration (1 hour)

Add a simple interface on the property detail page that:

  • Shows the property's on-chain status
  • Has a "Register on Blockchain" button (calls your contract)
  • Displays the transaction hash when complete

No backend needed. Just frontend + ethers.js.
